# Carta de aniversário para Sarah 🎀

Site de uma página só (`index.html`). O fundo animado, as gatinhas, a pata, a cena das cerejeiras e a música ficam **dentro do próprio arquivo**, então não há outras pastas nem arquivos para enviar.

```text
carta-sarah/
├── index.html
├── .nojekyll
└── README.md
```

## Publicar no GitHub Pages

1. Envie os 3 arquivos para a **raiz** da branch `main` do repositório `andersonbecker2009-cmyk/aniversario-sarah-ofc2` (GitHub → *Add file* → *Upload files*; marque que mostra arquivos ocultos se não aparecer o `.nojekyll`).
2. Em *Settings → Pages*: Source = *Deploy from a branch*, Branch = `main`, pasta = `/ (root)` → *Save*.
3. Depois de 1–2 minutos o site abre em: https://andersonbecker2009-cmyk.github.io/aniversario-sarah-ofc2/

## Observações

- A música só toca depois que a pessoa toca no botão ♪ (regra dos navegadores).
- O arquivo tem cerca de 4 MB; o primeiro carregamento no celular pode levar alguns segundos.
- Para ver localmente, basta abrir o `index.html` no Chrome.
